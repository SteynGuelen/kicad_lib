This project template provides a foundation for developing PCB designs at MPLab at Columbia University. It adds a custom designsheet with logo and a basic PCB with size 200x100mm.

I created this template during my internship at MPLab, which has been an incredible experience. It’s been a great opportunity to work on cutting-edge projects and collaborate with some brilliant minds.
- Steyn

Designing power electronics is like cooking — if you leave it on too long, things start to burn, and the smell is hard to get rid of.
